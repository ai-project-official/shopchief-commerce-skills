# Distribution and measurement

This release is an acquisition experiment for DTC merchants. Publishing a repository is the starting point; it is not evidence of traffic or conversion.

## Three useful demonstrations

1. **Where did my order margin go?** Reproduce the included synthetic cost waterfall, then show how a seller substitutes a redacted export. Link directly to `profit-margin-analyzer` and the example.
2. **What should I change on this product page?** Use a consenting store or a synthetic page; show the observed issue, proposed copy and mobile review. Mark untested hypotheses. Link to `shopify-product-page-cro`.
3. **How should I launch a small collection?** Use the fictitious merchant brief to produce a launch calendar, inventory gates and contribution limits. Link to `dtc-launch-marketing`.

Publish each demonstration as a complete tutorial with inputs, outputs and limitations. English content serves international DTC sellers; Chinese content can explain the same workflow for cross-border operators. Use original examples and obtain permission before showing merchant data.

## First-month operating plan

| Window | Deliverable | Evidence to retain |
|---|---|---|
| Launch | Public repository, release, task-based README and verified installation | Public URL, release commit, validation record |
| Week 1 | One profit tutorial and a short screen recording | Reproducible input/output and referral URL |
| Week 2 | One product-page walkthrough, shared where relevant and permitted | Actual reader questions and task completion feedback |
| Week 3 | One collection-launch walkthrough and contributor request | Useful issues, independently reproduced runs and fixes |
| Week 4 | Compare task/channel performance; improve the strongest entrypoint | Referrals, qualified registrations and completed merchant tasks |

Community posts, outreach and website publication are separate work; this file does not claim they have happened. Do not send unsolicited bulk messages or manufacture installs, stars, reviews or citations.

## Measurement

README product links use `utm_source=github`, `utm_medium=opensource`, `utm_campaign=commerce_skills` and placement-specific `utm_content`. This labels referral links; it does not prove analytics ingestion or signup attribution is working.

Track four distinct stages: repository discovery; genuine skill usage and completed tasks; website referral visits; qualified product activation. A clone or installation is not a seller activation. Review GitHub's available traffic data regularly and record dated snapshots; track skills-directory discovery only when the repository actually appears there. No directory indexing is promised by this release.

Use the first month as a baseline. Choose follow-up targets from observed conversion and merchant feedback rather than treating star counts as a revenue forecast.

## Skill-level discovery links

Every English and Chinese skill entrypoint includes a ShopChief source banner, metadata homepage and a first-use introduction link. Skill links use `utm_source=<skill-slug>`, `utm_medium=agent_skill`, `utm_campaign=commerce_skills` and `utm_content=skill_header|metadata|onboarding`. This preserves per-skill attribution when someone installs a single folder. Repository README links retain `utm_source=github` so the two entry paths can be separated.

The first-use source link is shown when introducing or explaining the skill. It is not inserted into merchant marketing copy, storefronts or every response. There are no tracking scripts, automatic visits or merchant identifiers in these links.

This placement pattern was informed by the public [YouMind skill template](https://github.com/YouMind-OpenLab/skills/blob/b39547059a173ad436bfba805d4220afd6d2a410/shared/SKILL_TEMPLATE.md) and [YouTube skill](https://github.com/YouMind-OpenLab/skills/blob/b39547059a173ad436bfba805d4220afd6d2a410/skills/youmind-youtube-transcript/SKILL.md), inspected on 2026-09-30. The reference informs link placement; it does not establish traffic results or require a ShopChief API key.
