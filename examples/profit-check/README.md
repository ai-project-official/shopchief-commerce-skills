# Profit example

The calculator, input and completed interpretation are bundled inside the [profit-margin-analyzer skill](../../skills/profit-margin-analyzer/assets/worked-example.md), so single-skill installation includes everything needed.

From a full repository checkout, run:

```sh
python3 skills/profit-margin-analyzer/scripts/profit_report.py --demo
```

From an installed skill folder, run `python3 scripts/profit_report.py --demo`. The expected JSON is in `assets/expected-report.json` inside that folder. See the worked example for input definitions and evidence limits.
